# THE WORLD TODAY — Wednesday, 25 November 2026

One image that sums up the world's news of Wednesday 25 November 2026, as a
newspaper front page: the CIA/ODNI cyberattack leads, with the Huawei guilty
verdict, Ukraine's strikes on Russian ships, the Houthi drone attack on a
Riyadh tower, the WHO evacuation from an Ebola hospital in DR Congo, England
levelling the T20 series in Australia, and the Thanksgiving turkey pardons.

## How it works

`main.ts` copies the finished front page (`entry.png`, 1024×1024, rendered
locally from `page.html`) to `$MAKEFUN_OUTPUT_DIR/entry.png`. It reads no
network and draws nothing at runtime — the same bytes come out on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
